# argo-plugins

Claude Code plugins that came out of building Argo, a personal executive-function
assistant. Each one is something we built for ourselves first, used daily, and only
then packaged.

```
/plugin marketplace add ragonc/argo-plugins
/plugin install <name>@argo-plugins
```

| plugin | what it does |
|---|---|
| [garmin-pull](garmin-pull/) | Pull your own Garmin Connect wellness and activity data into CSV, SQLite and JSON. Guided setup, partial selection, standard library only. |
